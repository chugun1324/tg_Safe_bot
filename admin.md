Админ-панель:
1) Вызывается командой /admin 
2) Сообщение в чате о том, что мы находимся в админ панель 
3) Кнопки:
	- Открыть спор (Выходят все споры)
	- Жалобы, по очередно выходят все жалобы
	- Блок\Разблок пользователей
	- Бд users 
4) Когда мы открываем определенный спор у нас выводиться 
	- Все медиа .zip которые кидал исполнитель 
	- id tg users каждого участника, (чтобы позже можно было написать) 
5) Жалобы просто поочередно можно будет просматривать
6) Блок\Разблок user будет подтягиваться из бд users 
6) БД users (поля)
 Таблица User:
	- id
	- tg id
	- status_user (Customer | Artist) true | false
	- status_block (true | false)
	- id_work (внешний ключ к другой таблице)
 Таблица work:
	- id
	- файлы users
